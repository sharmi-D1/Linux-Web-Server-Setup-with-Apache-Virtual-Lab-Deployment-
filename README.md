# 🌐 Linux Web Server Setup with Apache

## 📌 Overview
This project demonstrates the setup and configuration of a complete Linux-based web hosting environment in a virtual machine. It focuses on deploying a web server, managing access controls, and ensuring secure and functional website hosting.



## 🛠 Tools & Technologies
- Linux (CentOS / Ubuntu)
- Apache Web Server
- SELinux
- Virtual Machine (VM)



## ⚙️ Tasks Performed
- Installed and configured Apache Web Server
- Set up Virtual Hosts for domain-based hosting
- Configured domain mapping and directory structure
- Managed file permissions and ownership for secure access
- Configured SELinux contexts to allow web server functionality
- Tested website accessibility through browser validation
- Troubleshot server configuration and network-related issues



## 🔍 Key Learning Outcomes
- Gained hands-on experience in Linux system administration
- Understood web server configuration and hosting workflows
- Learned how to secure web services using permissions and SELinux
- Improved troubleshooting skills in real-world scenarios



## 💡 Why This Project?
This project simulates real-world web hosting environments where system administrators configure and secure servers for deployment. It provides practical exposure to managing live server environments and handling infrastructure challenges.



## 🔐 Security Considerations
- Applied proper file permissions and ownership
- Configured SELinux for controlled access
- Ensured secure web directory structure



## 🚀 Future Enhancements
